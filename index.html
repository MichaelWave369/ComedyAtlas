    Recurring comedy motifs

    Version 0.5 counts distinct timelines, not independently sourced performances. Two timelines may still describe the same original bit. Use Evidence to group duplicated sources.

    What does a resemblance % mean?

    A weighted comparison of phase proportions (30%), ordered transitions (25%), perceived energy shape (20%), hold placement (15%), and payoff placement (10%). All timing is normalized to each annotation's full duration. High scores mean similar structure, not that a performance is funny, original, or scientifically effective.

          11 / LOCAL LEARNING EXPERIMENT

          Predict the next beat.

          A small, explainable model learns annotated comedy structure, not whether something is funny.

          The first actually fitted model. A first-order, smoothed transition model learns which annotated comedy phase tends to follow the preceding one. A simple majority-phase baseline keeps the experiment honest. Training, validation, and evaluation run in your browser on feature annotations only. No audio, transcripts, user tracking, or server training.

          Ready to run locally.

          Start with synthetic annotations generated entirely for this project. Your personal Evidence notebook is used only when explicitly selected; it needs at least six eligible source groups. Nothing is saved or uploaded automatically.

          Validation: choose model smoothing

          Hyperparameters are selected by validation group-balanced log-loss, not test accuracy. Lower log-loss is better.

          Held-out test: baseline vs learned model

          These groups were never used to fit transition counts or choose smoothing. Repeatedly changing seeds after looking at test performance weakens the meaning of a final held-out benchmark.

          Held-out confusion matrix

          Ask the fitted model

          What the computer learned

          A small statistical transition table. It uses the previous annotated phase to estimate probabilities for the next one.

          What it did not learn

          Humor quality, audience reaction, social meaning, spoken language, comic intention, or what makes a particular joke successful.

          The baseline

          A comparator trained on the same source groups that always predicts the most common next phase. A more complicated system should not be celebrated merely for existing.

          Research limits

          The original demonstration is synthetic and uses repeated template families, so its accuracy cannot be generalized to real comedy. For user data, source group independence and permissions are self-reported, not verified. This is an exploratory tool, not an authorization to train on third-party recordings.

          Metric: group-balanced accuracy and log-loss, so each original source gets equal weight at evaluation even if it contains more annotated transitions.

          12 / COMEDY BRAIN RELIABILITY

          Does it hold up?

          Repeat source-group evaluations and see how much results depend on the split.

          One lucky seed is not a research result. Re-run v0.8's train-only Markov learner against its majority-phase baseline on different deterministic source-group splits. Validate smoothing within each split, then compare both models on the same held-out groups. Use paired resampling of whole sources to explore uncertainty. This is a sensitivity diagnostic, not a fresh external benchmark.

          What counts as reliability?

          Performance should not collapse when we change which original-source groups are held out. We compare the learned predictor with the same baseline on every split, instead of cherry-picking the nicest result.

          What does the interval mean?

          A descriptive spread across repeated, overlapping splits. Each per-split bootstrap samples whole source groups, so long sketches do not masquerade as hundreds of independent observations. These are not calibrated confidence intervals.

          Important limits

          The original synthetic examples reuse four fictional template families, so strong results cannot establish generalization to real comedy.

            No comedy-quality score, speech recognition, audio upload, paid service or external model is involved. Rights and source independence are not independently verified.

            13 / v1.0 RELEASE CANDIDATE

            Review the evidence.

            Group related performances by creative lineage, review their provenance, and test without borrowing from the same family.

            Original sources aren't always independent creative ideas. A repost, remix, and original clip may share one performance, while different performances may share a common template. The v1.0 Source Family Review Desk adds another layer: explicitly label related source families, quarantine conflicts, and withhold whole families during evaluation. Every review and permission claim is user-entered and unverified.
